# refs/ 是什么

这里放**每个会话的聊天标题条**截图（320×32 灰度 PNG），文件名 = 会话 id 把 `@` 换成 `_`，
例如 `wxid_OWNER.png`、`群id_chatroom.png`。

用途：走界面发送兜底时，`send_guard.py` 拿它跟当前标题条比对，确认自己点开的是对的人，
点了别的会话就会 `ABORT`，避免发错群。

- 不需要手工准备：第一次成功发送时 `send_guard.py` 会**自动**把当时的标题条存成参考图。
- 换机器 / 换主题 / 缩放比例变了，参考图会失效（尺寸或对比对不上），删掉重存即可。
- 只走 hook 直发（`127.0.0.1:30001`）时用不到这个目录。
