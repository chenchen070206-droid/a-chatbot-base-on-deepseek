# 微信聊天机器人 · 规则总览

> 一句话：它挂在微信上，只在「被叫到」之后的一分钟里正常聊天（被拍一拍只有 10 秒），其余时间基本安静；
> 会看图、存发表情包、被拍会回嘴、到点睡觉。

> 说明：这是一份**通用规则**文档，不含任何账号、联系人、群名、路径等个人信息。
> 具体名单和参数都在配置文件里，换人换号不需要改这份文档。

---

## 一、它在哪些会话里活动

| 项 | 说明 | 配置文件 |
|---|---|---|
| 监听的会话 | 一份列表，逐个指定（私聊或群） | `rooms.json` |
| 白名单 | rooms.json 里 enabled=true 的会话（即群/私聊勾了启用）；whitelist.json 只是自动生成的镜像 | `rooms.json` |
| 管理员 | 一行一个账号 id，**每轮现读**，改完不用重启；文件为空 = 谁都不能用它停机 | `admins.txt` |
| 私聊 vs 群 | 私聊默认「一直在聊」；群聊要靠触发（见第三节） | 代码里 |

> 三个文件都是空的也能跑：那就是「什么都不听、什么都不发」。

## 二、什么时候**完全**不说话

### 2.1 宵禁
- 每天 **00:30 – 07:30** 不读不回（时间可在 `settings.json` 的 `curfew` 里改）。
- 例外：宵禁开始那一刻给群发一句晚安、结束时发一句早安——每群每天各一次，
  内容按该群最近的聊天生成，用口语，不写「早点困」这种书面腔。

### 2.2 `/闭嘴` 静音（管理员指令）

| 在哪里发 | 作用范围 |
|---|---|
| 群里发 `/闭嘴 N` | **只停这个群** N 分钟 |
| 管理员私聊发 `/闭嘴 N` | **除管理员私聊外，所有会话都停** N 分钟 |
| `/闭嘴 0` | 立即解除全部静音 |

- 半角 `/`、全角 `／` 都认；消息里「含有」这条命令就算，不要求整条都是命令。
- 静音期间照样在听（能收到新的 `/闭嘴`），但不回任何消息。
- **管理员私聊永远豁免**：全体静音时，管理员私聊照常回。
- 静音解除时，如果静音期间有人说过话，会冒一句抱怨（要求一定带上「被捂嘴」的意思，语气偏生气）；
  期间没人说话就不吭声。手动 `/闭嘴 0` 解除也算「刚刚结束」。
- 非管理员发 `/闭嘴` → 回一句固定台词（调侃语气，不执行停机）；**该会话静音中就不回**。
- 静音期间**除了管理员改静音，其它一概不出声**：杂鱼台词、主动抛话题、饭点报菜单、
  宵禁晚安/早安播报都会跳过（用户 m07608）。

## 三、什么时候才说话（核心：1 分钟活跃窗口）

### 3.1 触发开窗
收到消息时，满足任意一条就开一个 **1 分钟**的活跃窗口（被拍一拍只开 **10 秒**）：

1. **被 @**（@ 它的昵称）
2. **消息以它的昵称开头**（只有 **10%** 概率真的开窗，没抽中就不回）
3. **被点名**：出现和它形象相关的称呼，或人设里的自称（同样 **10%** 概率开窗）
4. **聊吃的**：命中一份 41 个词的食物清单（吃、饭、外卖、宵夜、奶茶、火锅……）（同样 **10%** 概率开窗）
5. **被拍一拍**（被拍也开窗）
6. **它自己每回一次话**（窗口自动续 1 分钟）

> 私聊不受这条限制：私聊默认一直在窗口里。

### 3.2 窗口内也要「该回才回」
开了窗不等于什么都回，每条消息还要过一道判断：

1. 命中上面那些触发词 → 直接回
2. 没命中 → 交给模型判「跟前面聊的搭不搭」，搭才回，**拿不准就不回**

### 3.3 窗口里的随机性

| 机制 | 数值 | 说明 |
|---|---|---|
| 回复丢失 | **10%** | 该回的消息有 10% 概率直接不回（后续不受影响，不是惩罚） |
| 注意力（仅群聊）衰减 | 窗口内回满 **5** 次后，每次额外 **+5%** 静默概率（第 6 次 5%、第 10 次 30%…） | 只关当前窗口，不是永久闭嘴；被 @ 会清零重新算 |
| 久静开窗 | **我自己** ≥ **30 分钟**没说话时，来一条**没触发**的新消息，有 **5%** 概率直接开窗参与 | 每群 10 分钟只掷一次 |

### 3.4 主动说话（没人叫它的时候）

| 场景 | 规则 |
|---|---|
| 群里静了 **1 小时** | 之后每 **10 分钟**掷一次，**10%** 概率主动抛一句话题；群里一有新消息就重新计时 |
| 饭点报菜单 | **11:30–12:30**、**17:00–19:00** 各一次；进窗口时随机挑一个时间点，到点且最近 30 分钟群里有消息才发 |

> 主动说话只在**群聊**里，私聊不主动；宵禁期间一律不发。

## 四、回复长什么样

| 规则 | 值 |
|---|---|
| 一条消息 | **一句话**，≤ **30 字**（模型写长了会被切） |
| 一次回应 | 最多 **4 条**气泡，不截断内容 |
| 多条之间 | 间隔 **2–4 秒**随机 |
| 句尾 | **不加句号**（问号、感叹号、省略号照常） |
| 语气 | 口语、短句；少追问（不反问、不主动抛新问题）；别每次都用同一个口头禅 |
| 额度 | 一条「欠账」给 1–4 条机会，但必须都用来回这一条，**不能拿一次机会去补更早的旧话题** |
| 欠账 | 它最后一条消息之后、3 分钟内没回的才算欠账；超时的算翻篇 |
| 顺序 | 多条欠账按时间先后回，**一条一次出稿，不同欠账不合并、不互相带话** |

## 五、图片 / 表情包怎么处理

### 5.1 识别

| 项 | 规则 |
|---|---|
| 时间 | 只识 **5 分钟内**的新图，更早的不看 |
| 频率 | 每轮最多现场识 **1 张**；同一条只识一次（有缓存） |
| 失败 | 最多重试 **3 次**（间隔 1/2/3 秒），三次都不成 → 记成「无法识别」，以后永久跳过 |
| 坏图 | 打不开、没下全的，直接永久跳过，不反复重试 |

### 5.2 回不回
- **不在活跃窗口** → 只识别、不回。
- **在活跃窗口** → 跟文字一样走普通判定（触发词直接回；否则判相关性）。
- 旧规则「我最近说过话就算在话题里」「按概率抽签」**已停用**。

### 5.3 图里是它自己
- 判定：出现强特征词（大肥鱼 / 小肥鱼 / 鲸鱼娘 / 蓝鲸 / 虎鲸 / 鱼娘 / 鲸尾 / 本鱼 / 它的自称…）直接算；
  否则要「蓝发 / 蓝白 / 蓝毛」和「女仆 / 围裙 / 鲸 / 鱼尾 / 尾巴」同时出现；
  猫娘 / 狐娘 / 兔娘 / 犬娘这类**排除**。
- 行为：**100% 丢一张自己的表情包**（库里挑不到就只记一笔不回）。

## 六、表情包（收 / 存 / 发）

### 6.1 存

| 规则 | 值 |
|---|---|
| 存什么 | **只存「跟机器人形象相关」的表情**，其它表情一律不收 |
| 数量上限 | **无** |
| 保存间隔 | **无** |
| 查重 | ① 同一个文件 ② 画面感知哈希相似（汉明距离 ≤6）③ 注释相似度 ≥0.88 —— 任一条命中就不存 |
| 存放 | 一个本地目录，配套 `index.md`，每存一张追加一行「文件 / 画面内容 / 适用场景 / 关键词」 |

### 6.2 发

| 场景 | 概率 |
|---|---|
| 回话时配表情包（活跃窗口里） | **按语境判断**，合适才配、最多一张 |
| └ 窗口里别人刚发过表情包 | 会提示它「可以顺着接一张」 |
| 图片/表情**就是它自己** → 丢一张表情包 | **100%** |
| 被拍一拍 | 不配表情包 |

- 同一张表情 **15 分钟**内不重复用。
- GIF 走「文件通道」发出去，微信会把它变成**会动的表情**；PNG/JPG 走图片通道（是图片，不是表情）。

## 七、拍一拍

- 被别人拍 → **100% 回一句**，按被拍次数分三档语气：
  - 第 1 下：和善轻快（「拍我干嘛呀，我在呢」）
  - 第 2 下：有点不耐烦
  - ≥3 下：带火气（「手拿开，再拍试试」）
- 一律不爆粗口、不骂家人；一句 ≤25 字（火气版 ≤20），句尾不加句号，**不配表情包**。
- 拍一拍也算一次活跃触发。

## 九、技术底座（为什么它不抢鼠标）

- **读**：直接读微信本地数据库（只读），不碰界面。
- **发**：通过注入到微信进程里的 DLL 提供的本地 HTTP 接口发送，**不切窗口、不动鼠标键盘**；
  发完会回读数据库确认真的发出去了。
- 代价是**微信版本必须锁死**在 hook 支持的那个版本，升级就失效。
- 发送能力只有：文字、图片、文件（GIF 走文件通道会变成表情）。
  **没有**「自定义发送任意表情」的接口。
- 兜底：接口不可用时会退回「界面发送」（切前台 + 粘贴 + 回车，这时才占屏幕）；
  接口模式失败则不硬发。

---

## 十、已知限制 / 注意事项

1. **登录**：靠微信客户端本身，掉线要手机扫码确认；hook 只在微信进程活着时可用。
2. **版本锁定**：微信必须停在 hook 支持的版本，自动更新会打断发送通道。
3. **表情**：只能从本地表情库里挑着发；不能凭空把任意图片「变成微信表情」再发（GIF 走文件通道可以）。
4. **单账号**：一次只绑一个微信号，不影响同机其它账号的数据。
5. **上下文**：每次出稿带最近 50 条聊天 + 人设，token 约 1.6k（含缓存）。
6. **随机性**：上面所有概率都是「每次独立掷骰」，同一件事不保证每次一样。
